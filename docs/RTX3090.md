# RTX 3090: evidence and the missing matched test

Checked November 16, 2026. The retained historical reference is an RTX 3090 24-GB, 2 × Xeon E5-2686 v4, 128-GB RAM, 960 × 512, 192 frames, 24 fps, Euler, eight PDD steps, seed 2026103001: **217.417 s full-job cold latency**.

The embedded reference graph used `PathchSageAttentionKJ` with `sage_attention=auto` and `MiniMaxH3MemoryEfficientSageAttentionPatch`. This was not a pure BF16-attention baseline. The selected native kernel was not captured, and no matching hot repeat is retained. A different 177.853-s historical row has a different prompt/seed and is not a hot repeat of this case.

The 2080 Ti profile uses `ck_sol_all_int8_hybrid`: CK INT8 on one-based steps 1, 2, 7, 8; sparse Sol INT8 on 3, 4, 5, 6. No verified 3090 full-job timing with this same profile and matching parameters was found. The public table therefore leaves this timing empty.

Relevant primary sources were checked:

- [ComfyUI-sol-attn v0.6.2 release](https://github.com/Saganaki22/ComfyUI-sol-attn/releases/tag/v0.6.2) reports SM86 support and RTX 3090 Ti correctness validation, but explicitly says SM86 performance had not been formally benchmarked. Support on SM86 alone does not supply a timing for this custom hybrid.
- [ComfyUI issue 16150](https://github.com/Comfy-Org/ComfyUI/issues/16150) includes an RTX 3090 availability report, but no completed matching sparse timing.
- [ComfyUI issue 15263](https://github.com/Comfy-Org/ComfyUI/issues/15263) contains an RTX 3090 Sage benchmark using a different resolution/frame count and 20 steps. It cannot fill the matched eight-step hybrid row.

The same [issue's later RTX 3090 report](https://github.com/Comfy-Org/ComfyUI/issues/15263) also compares **Comfy Kitchen INT8 attention** with Sage and PyTorch attention on T2VA at **1344 × 768, 362 frames**, using ComfyUI 0.32.0, comfy-kitchen 0.2.31 and PyTorch 2.10.0+cu128. The author reports CK at **188 s/step, 1 h 07 min total, 230 W**. This uses dense CK rather than the CK/Sol hybrid, T2VA and a much larger workload, so it cannot be compared numerically with the 8-second 2080 Ti rows. The timing table does not independently label its step count; the surrounding comment discusses 1- and 20-step tests. Values are an external report, not reproduced here.

A future valid comparison needs the same model/quantization/PDD branch, frame count, resolution, eight-step schedule, hybrid attention routing, conditioning workload, timing boundary, cold/hot phase and documented system settings. Keep the 3090's native implementation separate from the SM75-only CUDA library in this repository. No new 3090 run was performed for this release.
